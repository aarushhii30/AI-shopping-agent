## 👩‍💻 Aarushi Sharma — Frontend Engineer & Product Lead

| Area | What Was Done |
|---|---|
| **Chat UI** | Built the full chat interface — messages, typing indicator, product cards inside chat |
| **Voice Assistant** | Integrated speech recognition — user can speak their query instead of typing |
| **Authentication Pages** | Built login and signup screens with form validation and error messages |
| **Checkout Flow** | Built all checkout steps — Shipping → Payment → Review → Order Success pages |
| **Cart Page** | Built cart UI with quantity controls, price summary, and promo code input |
| **Personalization** | Added recent searches, personalized welcome message based on browsing history |
| **Styling & Dark Theme** | Wrote all CSS — responsive dark UI, animations, mobile-friendly layout |
| **Shopify Product Display** | Rendered product cards from API response with image, name, price, and add-to-cart |
| **Product Documentation** | Wrote the full Product Thinking doc — problem, user journey, decisions, roadmap |
| **Frontend Bug Fixes** | Resolved merge conflicts, duplicate code, and syntax errors across all frontend files |

## 👨‍💻 MD. Khustar Noorani — Backend Engineer & Systems Architect

| Area | What Was Done |
|---|---|
| **Express Server** | Built the Node.js backend server with all API routes and middleware |
| **AI Integration** | Connected Groq (Llama 3.1) — AI understands what user wants and picks right products |
| **Shopify API** | Wrote GraphQL queries to fetch real products filtered by category and price |
| **Firebase Auth Backend** | Set up Firebase Admin SDK to verify user login tokens on the server side |
| **Cart & Checkout Logic** | Built cart state, GST calculation (18%), promo code validation, and step routing |
| **AuthContext & CartContext** | Built the React contexts that manage login state and cart across the whole app |
| **Session Management** | Built userSession utility — saves searches, viewed products, preferred categories |
| **API Error Handling** | Added fallbacks for when Shopify or AI fails — user always sees a helpful message |
| **System Architecture** | Designed how all five layers connect — Client, Auth, API, AI, and Database |
| **Technical Documentation** | Wrote the full Technical doc — architecture, decisions, security, performance roadmap |

## 🛠️ Tech Stack

```
Frontend    → React 18, React Router DOM, Axios, Lucide React, CSS Modules
Backend     → Node.js, Express.js
AI          → Groq API (Llama 3.1)
Commerce    → Shopify Storefront GraphQL API
Auth        → Firebase Authentication (JWT)
Database    → Firestore (chat sessions, user data)
Voice       → Web Speech API (Chrome/Edge)
```
